# Research Plan: AI Health Agents in Rails

## Main Question
Best practices for implementing AI health agents in Rails apps using OpenAI API

## Subtopics
1. **RubyLLM Integration** - RubyLLM patterns for chat with attachments (images, PDFs)
2. **RAG with pgvector** - Implementation patterns for retrieval-augmented generation in Rails
3. **Health Agent Patterns** - How agents observe, learn, and notify doctors
4. **Dual Interface Design** - Patient-specialist interface design patterns
5. **Medical AI Guardrails** - Scope limiting, off-topic handling for medical agents
6. **Medical Chatbot Principles** - Design principles for healthcare AI chatbots

## Synthesis Plan
Create a structured markdown report combining findings from all subtopics with source citations.
